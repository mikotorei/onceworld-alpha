## 3. 特記事項

### 3.1 禁域の液体 — 定義だけがある

`MATERIALS` に `forbidden_liquid` として登録され、`ui.slots` が**空配列**になっている。
`getMaterialMax("forbidden_liquid")` は動作するが、入力欄も計算も存在しない。

効果は「主人公のHP +1%/個」で、CLAUDE.md の HP計算式にも
`HP = (100 + VIT × 18) × (1 + 禁域の液体所持数 × 0.01)` と記載済み。
実装されていない理由は、**主人公のHPを表示する画面がサイト内に無い**ため。

### 3.2 ゴッドオブデビルアイ — ビルドシミュだけ計算未接続

統合計算機と詳細計算機では `getCriticalModifier` に渡されて計算に反映される。
ビルドシミュには `bs-devil-eye` の入力欄があるが、
`build-sim-ui.js` からの参照は `BS_PERSIST_INPUTS` の登録1件のみで、
**計算には一切使われていない**（`storage-survey.md` の R-6）。

### 3.3 属性別素材が1つの入力欄にまとめられている

以下は素材データ上5件ずつ存在するが、ツールでは属性を区別せず1欄で扱う。

| 素材群 | 素材数 | 入力欄 | ツール |
|---|---:|---|---|
| 魔法の解析書（火/水/木/光/闇） | 5 | `analysis-book` ほか | 統合 / 詳細 / ビルドシミュ / 天空回廊 |
| キノコ（赤/青/緑/光/闇） | 5 | `kinokoInput` | ペットステシミュ |
| ルミナスキノコ（火/水/木/光/闇） | 5 | `luminousCount` | 必要経験値 |

解析書については、使用魔法の属性を別途選ぶため実用上は問題になりにくい。
一方キノコ2種は、複数属性のペットを同時に扱う場面で所持数を分けられない。

### 3.4 スーパースクロール — 素材ページが無い

`MATERIALS` に `super_scroll` として定義され、`calcTotalStatPoints` にも
反映されているが、`content/item/` に対応する素材ページが存在しない。
素材一覧から辿れないため、効果や入手先を確認できない。

### 3.5 `analysis_book` も素材ページが無い

`MATERIALS` の `analysis_book`（解析書）は、素材データ上は
属性別の5ページ（`fire_magic_analysis` など）に分かれている。
`MATERIALS` の id と素材ページが1対1で対応しない唯一の例。

### 3.6 未実装素材が多い領域

未実装15件のうち、ツールそのものが存在しないため実装できないものが多い。

| 領域 | 該当素材 | ツールの有無 |
|---|---|---|
| アリーナ | 禁域のオブジェ / 禁域の砂時計 / 闘技王の遺装 / VIPケース | なし |
| ゴールド | 禁域のキューブ / ゴールデン小槌 | なし |
| 牢獄 | 牢獄の罠 | なし |

## 4. 実装するために情報が必要な点

未実装素材を実装する場合に、効果の詳細が不明で計算式を書けないもの。

### 4.1 効果量が不明

| 素材 | 効果テキスト | 不明な点 |
|---|---|---|
| 死刑囚の身代わり晩餐 | 主人公へのダメージを**少し**軽減させる | 1個あたりの軽減率（%か固定値か）。上限時の総軽減量。被ダメージ計算のどの段階で効くか（防御適用前か後か） |
| ソラノアエキス | モンスターが生成される時、**少し弱く**計算されて生まれる | 1個あたりの弱体率。対象ステータス（全ステか一部か）。「生成される時」の意味（出現時に固定されるのか、毎回か） |
| ゴールデン小槌 | LUCKに応じてドロップゴールド量が増える | LUCKとの関係式。所持数がどう効くか（所持数×係数×LUKか） |
| 冥府の指輪 | 所持数×10%の確率でアクセサリー経験値の上昇量が増える | 「上昇量が増える」の増加幅。確率は所持数×10%で上限100%か |
| 共有の焚火 | 召喚していないペットにも経験値が0.1%入る*1 | 所持数で0.1%が増えるのか固定か。`*1` の注記の内容 |
| 時空歪曲装置 | 討伐経験のあるボスが1%の確率で複数スポーン*2 | 所持数で確率が上がるのか。「複数」の数。`*2` の注記の内容 |
| 闘技王の遺装 | アリーナのモンスター達のレベル上限が上がる*3 | 1個あたりの上昇量。`*3` の注記の内容 |

素材データの `effect` にある `*1` `*2` `*3` `*4` の注記本文がどこにも無い。
補足があるなら、それも実装時に必要になる。

### 4.2 適用先が不明

| 素材 | 効果テキスト | 不明な点 |
|---|---|---|
| ハデスの兜 | ペットの最大レベルを1つ上げる | ペットステシミュのLv上限は現在1200固定。基準となる素の上限がいくつで、所持数がそのまま加算されるのか |
| 禁域のロック | 装備の強化上限が1アップ | 装備レベル（現在1100上限）か神階レベル（300上限）か、あるいは両方か |
| 牢獄の罠 | 牢獄の上昇レベルが100増える | 「牢獄の上昇レベル」の定義。`battle_king_relic_armor` の「レベル上限」との関係 |

### 4.3 ツールが無いため実装先の判断が必要

| 素材 | 効果 | 判断が必要な点 |
|---|---|---|
| 禁域のキューブ | 所持金上限が10億アップ | 所持金を扱うツールを作るか、素材ページの記載のみで済ませるか |
| 禁域のオブジェ | アリーナの勝利報酬 +1 | アリーナ関連ツールを作る予定があるか |
| 禁域の砂時計 | アリーナバトルの進行速度 +0.1% | 同上 |
| VIPケース | アリーナコインの所持上限 +10000 | 同上 |

### 4.4 既存実装の仕様確認

| 対象 | 確認したい点 |
|---|---|
| 属性別素材（3.3） | 解析書・キノコ・ルミナスキノコを属性別に分けて入力できるようにすべきか。ゲーム側で属性ごとに別カウントなのは確実だが、ツールとして分ける必要があるか |
| ゴッドオブデビルアイ（3.2） | ビルドシミュで計算に反映すべきか。反映するなら物理ダメージのクリティカル計算に入れる |
| スーパースクロール（3.4） | 素材ページを作るか。作るなら sell 値と weight の挿入位置 |
